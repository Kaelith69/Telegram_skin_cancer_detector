# 🚀 Usage

This page explains how to interact with the bot, what kinds of images work best, what the output means, and how to interpret the results responsibly.

---

## Basic Usage

1. **Start your bot** (`python bot.py` — see [Installation](Installation.md))
2. Open **Telegram** and find your bot by username
3. Send a **photo** of a skin lesion directly in the chat
4. Wait ~2 seconds
5. Read the response

That's it. No commands, no menus, no `/start` rituals required. Just send a photo.

---

## Understanding the Response

A typical bot response looks like this:

```
🧾 Diagnosis Result
• Condition:   Melanocytic nevi
• Confidence:  94.73%
• Type:        ✅ Harmless - Non-Cancerous

Medical Insight:
Melanocytic nevi (moles) are benign clusters of pigmented cells that appear on
the skin. They are very common and usually harmless.

Signs: Small, round or oval, evenly pigmented spots. Usually < 6mm in diameter.

Treatment: No treatment is usually needed. Removal may be considered for cosmetic
reasons or if changes are observed.

What to do: Monitor using the ABCDE criteria (Asymmetry, Border, Colour, Diameter,
Evolution). Schedule an annual dermatologist check-up.
```

### Field breakdown

| Field | What it means |
|-------|--------------|
| **Condition** | The predicted skin condition name from the HAM10000 classification model |
| **Confidence** | How certain the model is, expressed as a percentage (softmax probability × 100) |
| **Type** | Severity label from Gemini: ✅ Harmless / ⚠️ Potentially Harmful / ❗ Harmful |
| **Medical Insight** | Plain-English explanation, signs, treatment options, and recommended next steps — generated by Gemini 2.0 Flash |

---

## Severity Labels

The bot classifies every result into one of three severity tiers:

| Label | Icon | Meaning |
|-------|------|---------|
| Harmless - Non-Cancerous | ✅ | The condition is considered benign. Still worth monitoring. |
| Potentially Harmful - Pre-cancerous | ⚠️ | The condition may develop into cancer if untreated. **See a doctor.** |
| Harmful - Cancerous | ❗ | The condition is classified as malignant. **See a doctor immediately.** |

> ⚠️ **The bot's severity labels are AI-generated and not medically validated.** Do not use them as a substitute for professional diagnosis.

---

## Classifiable Conditions

The ViT model was fine-tuned on the [HAM10000 dataset](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/DBW86T) and can classify:

| Code | Full Name | Clinical Nature |
|------|-----------|----------------|
| `nv`    | Melanocytic Nevi | Benign moles — very common |
| `bkl`   | Benign Keratosis-like Lesions | Seborrheic keratoses, solar lentigines |
| `df`    | Dermatofibroma | Benign fibrous nodule |
| `vasc`  | Vascular Lesions | Angiomas, angiokeratomas, haemorrhages |
| `akiec` | Actinic Keratoses / Intraepithelial Carcinoma | Pre-cancerous, caused by UV exposure |
| `bcc`   | Basal Cell Carcinoma | Most common skin cancer, slow-growing |
| `mel`   | Melanoma | Most dangerous skin cancer — early detection is critical |

## Tips for Better Results

The model performs best on images that resemble the training data (dermatoscope images):

| ✅ Do | ❌ Don't |
|-------|---------|
| Use good lighting | Submit blurry or dark photos |
| Capture the lesion clearly, centred in the frame | Submit photos where the lesion is tiny in the corner |
| Use a neutral background if possible | Submit heavily filtered or edited images |
| Ensure the lesion is in focus | Submit screenshots of other medical images |
| Use the highest resolution available | Submit photos taken in bad lighting |

## Non-Photo Messages

If you send a text message (or anything that isn't a photo), the bot responds:

```
📎 Please send a clear photo of a skin lesion.
```

This is intentional. The bot is a single-purpose tool. It doesn't do conversation, commands, or trivia.

---

## Error Messages

| Message | What happened |
|---------|--------------|
| `⚠️ An error occurred while processing the image. Please try again.` | Something went wrong during model inference or image loading. Try sending the photo again. |
| `📎 Please send a clear photo of a skin lesion.` | You sent something that wasn't a photo. Send a photo. |

If errors persist, check the bot logs for details. See [Troubleshooting](Troubleshooting.md).

## ⚕️ Responsible Use

The bot is a **research and educational tool**. When using it:

- **Never** delay seeking medical care based on the bot's output.
- **Always** consult a dermatologist for any lesion that concerns you.
- **Remember** that AI confidence scores can be misleading — a 94% confidence in the wrong class is still wrong.
- **Use the ABCDE rule** as a personal monitoring tool: **A**symmetry, **B**order, **C**olour, **D**iameter, **E**volution.

If the bot says something is harmless and you're still worried — **trust your gut and see a doctor.** The bot won't be offended.
